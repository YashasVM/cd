CD / File sharing

Send a file.
Share a link or QR.

CD hands a local file to someone’s phone, browser, or terminal. This guide covers the terminal command and the skill agents use to share QR images in chat, including T3 Code.

The QR feature described here is available in the local CD build from this change. A previously installed CLI or skill may need updating.

1. How a handoff works

The sender keeps the file available. The recipient opens the receive link, scans its QR, or enters the share code. CD does not store a server copy for later download.

Local file → Live sender → Link / QR / code → Recipient

Share codes expire after 15 minutes and admit one receiver. The link and QR refer to the same transfer; they are two ways to open it. A saved QR image remains on disk after the transfer expires, but cannot extend its lifetime.

2. Send from a terminal

cdx send ./report.pdf

In an interactive terminal, this shows a share card with a code and scannable QR, then waits until the recipient verifies the file. Keep the command running; Ctrl-C cancels it.

cdx send ./photos ./notes.md
cdx receive 48291 --out ./downloads/

Several files or a folder arrive as one ZIP. The second example receives a transfer in another terminal; replace 48291 with the live code.

When stdout is captured by an agent, script, or pipe, sending runs in the background and returns as soon as the code is live. Plain output remains just the code. Use --detach to force background mode or --wait to stay in the foreground.

3. Save a QR for an agent chat

cdx send --json --qr /tmp/report-qr.png ./report.pdf

Choose a fresh PNG path in an existing directory. The command generates the image locally and returns one JSON object with code, url, filename, size, and the absolute qrPath. An existing image is never overwritten.

In code mode, construct the receive link from code: https://cd.yash0.in/#48291. The QR contains this same receive link. If CD_PUBLIC_URL is set, use that origin instead.

In T3 Code, reply with a link and a Markdown image using the returned absolute path:

[Receive report.pdf](https://cd.yash0.in/#48291)

![Scan to receive report.pdf](/tmp/report-qr.png)

Replace the example code and image path with the actual result. Keep the PNG available so the chat can render it. Chats without local-image support can still show the receive link and code.

4. Use a private link for sensitive files

cdx send --link --json --qr /tmp/private-qr.png ./secret.zip

Reply with the full url from JSON, including its #v1.… fragment, and embed qrPath. The QR holds that same private link.

Private links are end-to-end encrypted: the key stays in the URL fragment. Short-code mode uses TLS and lets the relay resolve the code to the transfer key. Anyone who guesses a live code can receive the file; choose --link when that matters.

5. Check delivery

cdx status 48291
cdx wait --timeout 10m --json 48291

A successful background send means the transfer is ready, not that the recipient has downloaded it. cdx wait reports delivery:

Exit codeMeaning
0The receiver verified every byte.
1The transfer failed. JSON includes the failure reason.
3The wait timed out; the send may still be live.

For private-link mode, pass the full link to status or wait. If a transfer expires or disconnects, send again and share the fresh link and QR.

6. Where the skill lives

The maintained skill is skills/cd-file-sharing/SKILL.md in the CD repository. The CLI bundles an identical copy at cmd/cdx/agentskill/SKILL.md for agent setup.

On this machine, the updated source is:

/home/yvm/code/cd/skills/cd-file-sharing/SKILL.md

The installed shared skill is ~/.agents/skills/cd-file-sharing/SKILL.md. That copy may be older until agent setup updates it.

cdx agent setup

This teaches supported agents to share files. The QR-aware skill tells agents to send with --json --qr, then return the receive link and embed the PNG.

To use the feature from this local checkout:

make cdx
./bin/cdx send --json --qr /tmp/new-qr.png ./report.pdf
./bin/cdx agent setup

Use cdx help send to check whether your installed binary supports --qr.
